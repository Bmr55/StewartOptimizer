# Supplemental optimizer materials

Start with the current [project README](../../../README.md), [quick start](../../../docs/quick-start.md), and [input reference](../../../docs/REQUIREMENTS.md).

- `examples/` contains historical layout examples. The runnable [sample requirements](../../../examples/sample-requirements.json) live outside the archive. The root UI accepts requirements, not layout imports.
- `schemas/Stewart_Requirements_Schema_v2.json` is a human-readable type/shape sketch, not a validating JSON Schema. Its companion Markdown explains the distinction.
- The v3/v4 specifications and comprehensive guide are historical proposals. Features such as CSV, integrated 3D/Pareto views and hybrid search are not implemented merely because they appear there.

Current implementation details are in [OPTIMIZER_REPRODUCTION.md](../../../docs/architecture.md), [cycle model](../../../docs/CYCLE_MODEL.md), and [results/export](../../../docs/RESULTS.md).
