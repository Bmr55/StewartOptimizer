# Archived materials

- [Simulator](simulator/README.md): the independently runnable previous p5 simulator, with its own locked build dependencies.
- `research/original/`: original layouts, layout schema, simulator notes and specifications.
- [Supplemental research](research/supplemental/README.md): historical optimizer proposals, type sketches and layout examples.

These documents are historical context, not a feature inventory for the current optimizer. Current instructions are in the [project README](../README.md) and [architecture guide](../docs/architecture.md). Runnable optimizer input is in [examples/sample-requirements.json](../examples/sample-requirements.json).
